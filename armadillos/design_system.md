# Design System - Armadillos

## Colors

| Name | Hex/RGB | Usage |
|------|---------|-------|
| **Background** | `#000000` / `rgb(0, 0, 0)` | Main body background |
| **Foreground Text** | `#FFFFFF` / `rgb(255, 255, 255)` | Main text color |
| **Primary Gold** | `#FFD696` / `rgb(255, 214, 150)` | Accents, Highlights, Buttons |
| **Secondary Grey** | `#808080` / `rgb(128, 128, 128)` | Subtitles, Secondary elements |

## Typography

- **Font Family**: `Inter, sans-serif`
- **Headings**: Uppercase, Bold (likely `Cinzel` or similar serif for Logo, `Inter` for headers)
